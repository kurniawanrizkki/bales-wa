Architecture & Data Flow

Alur Kerja Sistem BalasWA (WhatsApp Auto-Reply UMKM)

Integrasi WhatsApp Web Engine, Contextual Business Filter, Local SQLite, dan 9Router AI Gateway (Model cx/gpt-5.6-terra)

1. Pelanggan
Incoming Chat Pelanggan Kirim Pesan WA Kirim pertanyaan produk, harga, stok, alamat, atau pesan order.
↓
Menunggu respon otomatis bot...
(SLA balasan: ~1-3 detik)
↓
Success Reply Pelanggan Terima Balasan Jawaban sopan, padat, dan faktual sesuai data toko terkini.
2. WA Engine (Chromium)
Event message_create whatsapp-web.js menangkap msg.from dan msg.body.
↓
Filter Pesan Non-Bisnis • Abaikan grup (isGroupMsg)
• Abaikan broadcast & status WA
• Abaikan chat pribadi di luar konteks
↓
Filter Reject Abaikan Chat (Skip) Tidak membalas pesan personal agar kuota & privasi aman.
↓
client.sendMessage() Kirim teks balasan ke nomor pelanggan melalui Chromium.
3. Logic & Context
Cek Balasan Instan Pola salam (Hai/Halo) atau pesan order format tetap?
↓
Balasan Instan Langsung balas template cepat tanpa panggil AI (hemat kuota).
↓
Prompt Builder Build Context Toko: • Data Toko & Jam Operasional
• Katalog Produk & Stok Terkini
• Riwayat 6 Pesan Terakhir
• Prompt Khusus Pemilik
↓
Database Log Catat Riwayat & Kuota Simpan log di chat_logs dan kurangi kuota trial / paket.
4. 9Router AI Gateway
↓
API Inference POST /v1/chat/completions model: cx/gpt-5.6-terra
temperature: 0.7
max_tokens: 600
↓
Hasil Balasan AI AI menyusun jawaban berbasis konteks usaha tanpa boleh mengarang fakta/stok.
5. Pemilik Usaha & DB
Dashboard Web Kelola Data Usaha: • /app/profile Profil Toko
• /app/products Produk & Stok
• /app Scan QR & System Prompt
• /app/history Pantau Chat Log
↓
SQLite Storage Database Lokal (app.db): • users: Akun & Token
• business_profiles: Info Toko
• products: Harga & Stok
• chat_logs: Riwayat Chat
Perubahan harga atau stok pada dashboard langsung terpakai pada chat berikutnya secara realtime.
